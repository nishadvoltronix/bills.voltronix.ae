# Production readiness — 29 October 2026

## Current scope: typed manual entry with Zoho Books synchronization

The requested release keeps **Save and sync** for manually entered invoices. Use [MANUAL_DEPLOYMENT.md](MANUAL_DEPLOYMENT.md), [current verification evidence](BOOKS_PRODUCTION_VERIFICATION.md), and `npm run check:sync`. The production template selects `MANUAL_ENTRY_ONLY=false` and Books networking for setup, while financial-write flags remain false until operational verification. The normal deployment includes web/proxy/sync; OCR/scanner intake and CRM lookup are optional. OAuth callback locations suppress nginx error messages that could contain raw callback queries; sanitized access statuses remain available.

Production readiness requires target MySQL/migration acceptance, real company membership, exact Books grants/accounting/supplier mappings, verified operating destinations, real jobs, private storage, a supervised sync worker, and confirmed bill/attachment delivery in Books. Restart persistence and backup recovery also require host acceptance. The prior assessment below includes CRM-specific work that is outside this release, but its Books prerequisites remain applicable. Historical local-only browser tests did not exercise production posting.
