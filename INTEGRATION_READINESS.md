This digest/record is not a substitute for approval. Only then enable test mode and Books writes for the approved window; legacy production permission remains false. Complete consent and verify vendor mappings for each selected test destination separately.
5. Create one clearly fictional, non-discounted, single-currency invoice with a verified clean original and exact expected net/VAT/gross values. Use two users for entry and independent approval. Select the exact authorized Books organization on the approved bill, queue once and run `npm run worker:sync -- --limit=1` from the authorized host. Confirm the stable reference, destination, remote bill identity, currency and totals before attachment processing. Record local job/attempt/audit IDs without credentials or invoice bodies. 6. Process its attachment separately; download and compare its SHA-256 with the original. Repeat enqueue and confirm one remote bill and one canonical local recognized expense. Recording a local payment must not enqueue another bill. Multiple distinct originals remain blocked unless the provider contract is separately verified.
7. Use controlled fault injection only in the authorized test environment for a lost post-create response, attachment failure, 429/exhaustion and revoked authorization. Deterministic tests already cover these faults; never deliberately overload a provider to manufacture 429s.
8. Separately validate OCR against approved redacted files (missing/low-confidence values, duplicate invoices, mismatched totals and multipage documents), and CRM import against explicitly authorized **sandbox** Deals. Verify `JobDealNumber`/`Amount`, duplicates/missing IDs/currency and existing-job updates. No production financial records or CRM expense writes are part of this test.
9. Disable write/test/network flags and stop workers when the approved window ends. Retain results, unknown operations and audit history. Revoke/rotate test authorization as agreed. Obtain separate approval for any provider cleanup, release, DNS or future production change; none is authorized by this checklist.
